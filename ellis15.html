How this wormhole visualization works

Geometry and coordinates

This model uses the symmetric, massless Ellis wormhole (m = 0). Its spatial metric is dl² + (l² + a²)dΩ². The parameter a is the throat radius, set by the throat-size slider. The signed proper-radial coordinate l runs continuously through the throat: red room for l < 0, blue room for l > 0, and the throat at l = 0.

The areal radius is r = √(l² + a²). It has its minimum value a at the throat, so the camera never moves through a solid sphere's interior. The sign of l, rather than a separate room switch or a crossfade, identifies the side.

Camera movement

Movement input is split into radial and sideways components in the local camera frame. Radial motion changes l; sideways motion changes the angular position. The displayed xyz position is reconstructed using r. The room changes when the camera crosses l = 0. This is an interactive navigation control, not a model of a freely falling observer.

How the image is rendered

A separate light ray is traced for each screen pixel. The ray's path is integrated in the Ellis geometry with a fourth-order Runge–Kutta method, using the conserved impact parameter to describe its angular motion. The ray is followed until it reaches a room wall; that wall's red or blue color is selected from the sign of l at the hit. This lets a view into the other room come from rays that actually pass through the throat.

Controls and scope

Ray steps sets the number of integration steps per ray (more steps cost more rendering time). Wall grid line thickness changes the drawn grid width; it is a visual setting. The wall shading and grid are illustrative. This is a static ray-path visualization, not a complete simulation of materials, reflected light, or time-dependent gravitational physics.
